# Clinical Trial Storytelling

## Overview

This project is an interactive data story that explores the barriers to enrollment in clinical trials. It aims to highlight who gets excluded from these trials and why this is a design problem rather than a patient problem. The story is presented as a single-page web application built using plain HTML, CSS, and JavaScript, without any frameworks or build tools.

## Project Structure

The project consists of the following files and directories:

- **index.html**: The main HTML file that serves as the entry point for the web application.
- **css/**: Contains stylesheets for the project.
  - **reset.css**: CSS reset styles for consistent rendering across browsers.
  - **styles.css**: Main styles for layout, typography, and color schemes.
- **js/**: Contains JavaScript files for functionality.
  - **main.js**: Initializes the application and manages the overall flow.
  - **animations.js**: Handles animations throughout the project.
  - **funnel.js**: Manages the enrollment funnel visualization.
  - **map.js**: Responsible for rendering the map visualization using Leaflet.js.
  - **barriers.js**: Handles the barrier breakdown visualization.
  - **representation.js**: Manages the representation gap visualization.
  - **what-if.js**: Implements the "What If?" slider functionality.
- **data/**: Contains the data used throughout the project.
  - **data.js**: Fictional but realistic data for the enrollment funnel, barrier breakdown, and more.
- **README.md**: Documentation for the project, including setup instructions and project goals.
- **PROJECTBRIEF.MD**: Outlines project specifications, story structure, and design guidelines.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open `index.html` in your web browser to view the interactive data story.
3. Ensure you have an internet connection for any external resources (e.g., Leaflet.js for maps).

## Project Goals

- To create a polished, editorial-quality web experience that tells a compelling story about clinical trial enrollment barriers.
- To use invented but realistic data to illustrate the challenges faced by patients in accessing clinical trials.
- To engage users through interactive visualizations and human stories that highlight the importance of inclusivity in clinical research.

## Data Story

The data story follows a fictional clinical trial's enrollment journey, showcasing various barriers such as geography, transportation, digital access, work schedules, and language. The narrative emphasizes that these barriers are design problems that can be addressed to improve patient access to clinical trials.

## Acknowledgments

This project is a design exercise and does not represent real data or studies. All data is fictional and illustrative, created to serve the narrative of the story.
